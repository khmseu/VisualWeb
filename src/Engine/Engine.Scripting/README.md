# Engine.Scripting

Phase-1 placeholder for the V8 host boundary and eventual script/DOM bindings.
The native embedding approach is deferred; do not substitute another runtime.
Per-tab V8 isolates supplement, not replace, renderer process isolation.

Official document IDs: `ecmascript`, `webidl`, and `html` for the event loop.
See the [standards workflow](../../../docs/standards.md) and
[architecture](../../../docs/architecture/overview.md).
