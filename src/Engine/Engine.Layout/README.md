# Engine.Layout

Phase-1 placeholder for layout trees, block/inline formatting and line breaking.
Later phases add flexbox, grid, tables and other layout modes; none exist yet.

Inputs: DOM, computed CSS and text metrics. Official document IDs: `css-box`,
`css-display`, `css-inline`, `css-text`, `css-values`.
See the [standards workflow](../../../docs/standards.md).
