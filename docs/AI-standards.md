# AI Standards References

Here are the references for the standards discussed:

​WebMCP (Web Model Context Protocol): Developed under the W3C Web Machine Learning Community Group. The specification draft is available at <https://webmachinelearning.github.io/webmcp>.

​Browser AI APIs / WebNN (Web Neural Network API): Developed by the W3C Web Machine Learning Working Group. The standard specification is published at <https://www.w3.org/TR/webnn>.

​WebDriver BiDi (Bidirectional Protocol): Developed by the W3C Browser Testing and Tools Working Group. The standard specification is located at <https://w3c.github.io/webdriver-bidi>.

​Accessibility Tree Standards (WAI-ARIA): Developed by the W3C Accessible Rich Internet Applications Working Group. Specifications are hosted at <https://www.w3.org/TR/wai-aria>.
